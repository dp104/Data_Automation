2. Websites

One link per line: a listing, category or search-results page works best (for example a category of products or a company's jobs page). The tool reads every result, follows "next page", and opens each item's page for full details.

Use only websites whose terms allow collecting their data. The tool follows each site's robots rules and pace, skips pages the site asks not to be collected, and slows down if a site asks it to.
