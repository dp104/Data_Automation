Custom scraping: any website, your own columns

Products, jobs, listings, directories, courses: show the tool your sample sheet and one or two pages where those values appear. It learns where each value sits, then reads every similar page on the site.

No AI and no paid APIs: values are read straight from the pages. A column the site does not show stays blank, or gets a value you type. Pages with missing values are listed in a review file.
Works best on sites where every item has its own page with the same layout, such as product, job, property or profile pages.
